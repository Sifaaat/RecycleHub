# ♻️ RecycleHub

![Node.js](https://img.shields.io/badge/Node.js-20+-green?logo=node.js)
![Express.js](https://img.shields.io/badge/Express.js-Backend-black?logo=express)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Database-blue?logo=postgresql)

![License](https://img.shields.io/badge/License-MIT-yellow)

RecycleHub is a full-stack web application designed to promote sustainable waste management. It allows users to register, log in securely, and manage recyclable waste items through a simple and user-friendly interface.

## ✨ Features

- 🔐 Secure user authentication using JWT
- 👤 User registration and login
- ♻️ Add recyclable waste items
- ✏️ Update existing items
- 🗑️ Delete items
- 📋 View all recyclable items
- 🔍 Search and browse available items
- 🗄️ PostgreSQL database integration
- 📱 Responsive user interface
- ⚡ RESTful API with Express.js

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Sifaaat/RecycleHub.git
```

### Navigate to the project

```bash
cd RecycleHub
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
PORT=5000

DATABASE_URL=your_postgresql_connection_string

JWT_SECRET=your_secret_key
```

### Run the application

```bash
npm start
```

or

```bash
node app.js
```
